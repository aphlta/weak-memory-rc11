## Overall Theme & Style

- Pattern: Minimal Single Column
- Style: 在推荐系统基础上收敛为“正式学术 + 清晰块状信息”
- Motif: 大留白、深蓝主色、青色强调、浅底卡片、细边框

## Color Palette

| Token | Value | Usage |
|-------|-------|-------|
| Navy | 123B66 | 主标题、深色区块 |
| Cyan | 0891B2 | 强调色、编号、连接线 |
| Soft Cyan | D9F3F8 | 强调底色 |
| Slate | 4B5563 | 正文辅文 |
| Ink | 1F2937 | 主正文 |
| Surface | F8FAFC | 页面背景 |
| Card | FFFFFF | 卡片背景 |
| Rule | D7E3EA | 分隔线、边框 |
| Green | 16A34A | 正向成果强调 |

Palette relation: 以深蓝为主色建立学术与稳定感，以青色做结构强调，再用绿色仅在“成果/可行性”处做少量正向标记，避免页面过于单调。
