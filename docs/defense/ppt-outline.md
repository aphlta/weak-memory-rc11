## 建议的答辩追问准备

### 1. 为什么选 RC11，而不是完整 C++11？

- 因为硕士阶段更适合先做代表性子模型
- RC11 已经能覆盖关键弱内存难点
- 有利于把创新点集中在验证效率上

### 2. 你的创新点和已有工具相比在哪里？

- 不在重新实现已有语义，而在执行图约简与验证效率改进
- 强调“减少搜索规模”的方法贡献

### 3. 为什么先做 race 和 assertion？

- 这是最典型、最易评价的两类验证任务
- 有利于形成清晰实验结果
- 后续也容易扩展到库验证或更复杂性质

### 4. 你如何证明方法有效？

- 通过 litmus tests 与小型 benchmark
- 比较约简前后的时间、空间和错误发现能力
