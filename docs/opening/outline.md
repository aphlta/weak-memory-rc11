## 一、题目

面向 RC11 弱内存模型的并发程序自动验证与状态空间约简方法研究

可选保守版本：

面向 RC11 的弱内存并发程序自动验证方法研究

## 二、摘要

- 研究对象：`RC11 / RA` 弱内存子模型
- 核心问题：弱内存执行复杂、候选执行数量过多、自动验证效率不足
- 主要方法：程序执行表示 + 状态空间约简 + 自动验证原型
- 预期结果：支持数据竞争与断言违例检测的工具原型

## 三、研究背景与意义

### 1. 背景

- 现代处理器与编译器采用弱内存模型以提升性能
- 顺序一致性假设无法覆盖真实并发行为
- C/C++11 并发语义虽然形式化，但验证成本高

### 2. 理论意义

- 促进 weak memory 形式化语义向自动验证落地
- 缩小语义模型与实际工具之间的距离

### 3. 工程意义

- 为并发库、底层系统代码和教学型验证平台提供工具基础

## 四、国内外研究现状

### 1. 弱内存模型形式化

- 综述 weak memory formalisms、执行影响和未来方向
- 明确 operational 与 axiomatic 两类描述路线

### 2. 语言级并发语义

- C/C++11 并发模型 operational 化
- 为后续自动验证奠定基础

### 3. 自动验证与工具化

- 程序变换
- 抽象机器
- 执行图搜索
- operational verification 与 axiomatic reasoning 的统一

### 4. 并发库验证

- 从 litmus tests 走向并发库与模块化推理

### 5. 现有不足

- 状态空间爆炸明显
- 一些方法工程实现复杂
- 缺少兼顾正确性、效率和可扩展性的轻量框架

## 五、研究目标

1. 构建适用于 `RC11` 的程序执行表示
2. 设计弱内存执行图约简策略
3. 实现自动验证算法与工具原型
4. 在 benchmark 上验证正确性与效率

## 六、问题边界

### 纳入范围

- `RC11 / RA` 子模型
- 小型并发程序
- 数据竞争检测
- 断言违例检测

### 暂不纳入

- 完整 C/C++11 标准边界语义
- 工业级超大规模项目
- GPU 与异构弱内存
- 复杂时序逻辑性质

## 七、研究内容

### 1. 程序执行表示

- 程序事件建模
- `reads-from` 关系
- `modification order`
- `happens-before`
- 候选执行图构造

### 2. 状态空间约简

- 分析冗余执行来源
- 设计约简规则
- 证明约简正确性或给出可信说明

### 3. 自动验证算法

- 数据竞争检测
- 断言违例检测
- 反例执行生成

### 4. 原型工具实现

- 输入格式设计
- 执行图构造模块
- 错误检测模块
- 结果输出模块

### 5. 实验评测

- litmus tests
- 小型并发 benchmark
- 约简前后时间对比
- 约简前后空间对比
- 错误发现能力对比
