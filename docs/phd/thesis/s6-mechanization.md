# S6：机械化证明范围说明（可选，中后期）

> 对应路线图 **S6**。本稿只定范围与分期，**不**在本阶段建立完整 Coq/Isabelle 仓库。  
> 理论源：[`THEORY-v1.md`](../THEORY-v1.md)；语义边界：[`RC11-ALIGNMENT.md`](../RC11-ALIGNMENT.md)。

---

## 1. 目标与非目标

**目标**：将 T2⁺ / T2⁺⁺ 的核心引理从「证明纲要」提升为机器检查证明，降低论文审稿对纸面证明的质疑。

**非目标（明确不做进 S6 验收）**：

- 完整 RC11 / 完整 `psc` 的机械化；  
- 与 herdtools / `cpp11_simp` 的互模拟；  
- 将 Python 验证器抽取为证明助手可执行语义（可作为更远期工作）。

---

## 2. 建议工具链

| 选项 | 优点 | 风险 |
| --- | --- | --- |
| **Coq** | 社区弱内存/图模型先例较多；可与现有 RC11 形式化工作对照 | 学习曲线；需自建子集编码 |
| **Isabelle/HOL** | 可读证明脚本接近数学叙述 | 弱内存现成库相对分散 |

**默认建议**：Coq + 自建「迷你执行图」编码（事件、`po`/`rf` 赋值、存在性 `mo` 谓词），不依赖完整外部 RC11 库，以免范围膨胀。

---

## 3. 分期交付（建议）

### S6a — 最小可信核（优先）

形式化并证明：

1. 观察投影仅依赖 \(\mathsf{Obs}\) 相关读上的 `rf`（引理 1 的离散版）；  
2. 无关读存在性扩展不缩小观察结局集合（引理 2–4 的组合）；  
3. 得到 \(\mathsf{Out}=\mathsf{Out}_R\)（T2⁺ 的结局部分）。

**验收**：仓库内可 `make` 通过的证明脚本 + 1 页论文附录说明编码与假设。

### S6b — 布尔性质与 IND

- \(\mathsf{Prop}\) 保持（引理 5）；  
- IND 违例为空时噪声读可排除；非空时 promote 恢复（引理 6 的简化陈述）。

### S6c — 值维 T2⁺⁺

- identity / value 维划分的假设编码；  
- 引理 7–8 + T2⁺⁺。

可与论文「附录：机械化」对应；主文仍保留纸面证明结构。

## 4. 编码设计要点（避免翻车）

1. **一致性谓词与论文第 3 章一致**：`rf` + 存在性 `mo`（可先把 SC 建成可选公理，S6a 甚至可先在无 SC 的子语言上证明）。  
2. **先证明「有限程序、有限写集」上的命题**，再谈一般化。  
3. **不要**一上来编码完整 `sw` 全部 fence 模式；S6a 可用「抽象 `sw` 关系 + 假设 acquire 读∈相关集」参数化。  
4. 与 Python 的对应写成「信任边界」表：哪些引理由机器证明、哪些仍由 `compare_reduction` 实验守门。
